1.2 Measuring and Constructing Segments
Segment length is a number, not just a picture — and the Segment Addition Postulate and the Midpoint definition turn that number into an algebra tool. This section goes past single-step "add the two pieces" problems into equations with a variable on both sides, midpoints of midpoints, and word problems where you must first decide which points are the endpoints before any arithmetic happens. Expect to justify each step (postulate or definition) as much as to compute the final number.

Examples

Example 1: Distance on a number line
Find ABABAB if AAA is at −3-3−3 and BBB is at 555 on a number line.
Solution
Distance is the positive gap between coordinates.
Identify the formula: distance between two points on a number line is ∣x2−x1∣|x_2 - x_1|∣x2​−x1​∣ (order doesn't matter because of the absolute value).
Substitute: AB=∣5−(−3)∣=∣8∣AB = |5 - (-3)| = |8|AB=∣5−(−3)∣=∣8∣.
Answer: AB=8AB = 8AB=8.
Example 2: Segment Addition Postulate
BBB is between AAA and CCC. If AB=4AB = 4AB=4 and BC=7BC = 7BC=7, find ACACAC.
Solution
B is between A and C, so the two small pieces add to the whole.
Identify the relationship: since BBB is between AAA and CCC, the Segment Addition Postulate applies: AB+BC=ACAB + BC = ACAB+BC=AC.
Substitute the known values: AC=4+7AC = 4 + 7AC=4+7.
Answer: AC=11AC = 11AC=11.
Example 3: Find a missing part
BBB is between AAA and CCC. If AC=20AC = 20AC=20 and AB=8AB = 8AB=8, find BCBCBC.
Solution
Start from the same postulate, but solve for the middle piece instead of the whole: AB+BC=ACAB + BC = ACAB+BC=AC.
8+BC=208 + BC = 208+BC=20
BC=20−8BC = 20 - 8BC=20−8.
Answer: BC=12BC = 12BC=12.
Example 4: Midpoint doubles the half
MMM is the midpoint of AB‾\overline{AB}AB. If AM=9AM = 9AM=9, find ABABAB.
Solution
M splits AB into two equal pieces, AM and MB.
Identify: a midpoint splits a segment into two congruent pieces, so AM=MBAM = MBAM=MB.
Since AM=9AM = 9AM=9, also MB=9MB = 9MB=9; then AB=AM+MB=9+9AB = AM + MB = 9 + 9AB=AM+MB=9+9.
(Shortcut for any midpoint problem: AB=2⋅AMAB = 2 \cdot AMAB=2⋅AM.)
Answer: AB=18AB = 18AB=18.
Example 5: Midpoint algebra
MMM is the midpoint of PQ‾\overline{PQ}PQ​. If PM=3x+1PM = 3x + 1PM=3x+1 and MQ=5x−5MQ = 5x - 5MQ=5x−5, find xxx.
Solution
Set the two halves equal, since a midpoint makes them congruent: PM=MQPM = MQPM=MQ.
3x+1=5x−53x + 1 = 5x - 53x+1=5x−5
1+5=5x−3x⇒6=2x1 + 5 = 5x - 3x \Rightarrow 6 = 2x1+5=5x−3x⇒6=2x
x=3x = 3x=3.
Check: PM=3(3)+1=10PM = 3(3)+1 = 10PM=3(3)+1=10 and MQ=5(3)−5=10MQ = 5(3)-5 = 10MQ=5(3)−5=10 — equal, as required. ✓
Example 6: Congruent segments and transitivity
AB‾≅CD‾\overline{AB} \cong \overline{CD}AB≅CD and CD‾≅EF‾\overline{CD} \cong \overline{EF}CD≅EF. If AB=12AB = 12AB=12, find CDCDCD and EFEFEF, and name the property that lets you compare ABABAB and EFEFEF directly.
Solution
Definition of congruent segments: congruent means equal length. AB‾≅CD‾⇒CD=AB=12\overline{AB}\cong\overline{CD} \Rightarrow CD = AB = 12AB≅CD⇒CD=AB=12.
CD‾≅EF‾⇒EF=CD=12\overline{CD}\cong\overline{EF} \Rightarrow EF = CD = 12CD≅EF⇒EF=CD=12.
Since AB=CDAB = CDAB=CD and CD=EFCD = EFCD=EF, the Transitive Property of Equality gives AB=EFAB = EFAB=EF without re-measuring.
Answer: CD=12CD = 12CD=12, EF=12EF = 12EF=12.
Example 7: Solve with Segment Addition
BBB is between AAA and CCC. AB=2xAB = 2xAB=2x, BC=x+4BC = x + 4BC=x+4, and AC=19AC = 19AC=19. Find xxx.
Solution
The two algebraic pieces must add to the given whole.
Write the postulate as an equation: AB+BC=ACAB + BC = ACAB+BC=AC.
2x+(x+4)=192x + (x + 4) = 192x+(x+4)=19
3x+4=19⇒3x=15⇒x=53x + 4 = 19 \Rightarrow 3x = 15 \Rightarrow x = 53x+4=19⇒3x=15⇒x=5.
Check: AB=10AB = 10AB=10, BC=9BC = 9BC=9, and 10+9=1910 + 9 = 1910+9=19. ✓
Example 8: Midpoint coordinate on a number line
AAA is at 222 and BBB is at 141414. Find the coordinate of the midpoint MMM.
Solution
The midpoint coordinate is the average of the two endpoints.
Formula: the midpoint coordinate is the average of the endpoints, M=xA+xB2M = \dfrac{x_A + x_B}{2}M=2xA​+xB​​.
M=2+142=162M = \dfrac{2 + 14}{2} = \dfrac{16}{2}M=22+14​=216​.
Answer: M=8M = 8M=8.
Example 9: Find a missing endpoint
MMM is the midpoint of AB‾\overline{AB}AB. AAA is at 444 and MMM is at 101010. Find BBB.
Solution
Use the midpoint formula, but solve for the unknown endpoint instead of the midpoint: M=A+B2M = \dfrac{A+B}{2}M=2A+B​.
10=4+B2⇒20=4+B10 = \dfrac{4+B}{2} \Rightarrow 20 = 4 + B10=24+B​⇒20=4+B
B=16B = 16B=16.
Check: the midpoint of 444 and 161616 is 202=10\dfrac{20}{2}=10220​=10. ✓
Example 10: Nested midpoints — a hallway word problem
A water fountain FFF is at mile-marker 555 and a door DDD is at marker 353535 along a straight hallway. A bench BBB is placed at the midpoint of FD‾\overline{FD}FD, and a trophy case TTT is placed at the midpoint of FB‾\overline{FB}FB. Find the coordinates of BBB and TTT, and find FTFTFT.
Solution
Find BBB first, since TTT depends on it: B=F+D2=5+352=402=20B = \dfrac{F+D}{2} = \dfrac{5+35}{2} = \dfrac{40}{2} = 20B=2F+D​=25+35​=240​=20.
Now find TTT, the midpoint of FB‾\overline{FB}FB: T=F+B2=5+202=252=12.5T = \dfrac{F+B}{2} = \dfrac{5+20}{2} = \dfrac{25}{2} = 12.5T=2F+B​=25+20​=225​=12.5.
Finally, FT=∣T−F∣=∣12.5−5∣=7.5FT = |T - F| = |12.5 - 5| = 7.5FT=∣T−F∣=∣12.5−5∣=7.5.
Answer: B=20B = 20B=20, T=12.5T = 12.5T=12.5, FT=7.5FT = 7.5FT=7.5.
