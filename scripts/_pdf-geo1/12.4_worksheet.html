12.4 Permutations and Combinations
A permutation counts ordered arrangements — position matters, so swapping two chosen items creates a different outcome: nPr=n!(n−r)!_{n}P_{r}=\dfrac{n!}{(n-r)!}n​Pr​=(n−r)!n!​. A combination counts unordered selections — swapping two chosen items gives the same outcome (a committee is a committee no matter what order you name its members): nCr=n!r!(n−r)!=nPrr!_{n}C_{r}=\dfrac{n!}{r!(n-r)!}=\dfrac{_{n}P_{r}}{r!}n​Cr​=r!(n−r)!n!​=r!n​Pr​​. The single most important skill here is deciding which one applies before computing anything — ask "does order/role matter?" This worksheet also combines permutations/combinations with the Fundamental Counting Principle, restrictions (a specific person must/must not be included or placed), and probability.

Examples

Example 1: Factorial
Evaluate 6!6!6!.
Solution
Identify: n!n!n! means multiply all whole numbers from nnn down to 111.
Compute: 6!=6×5×4×3×2×1=7206!=6\times5\times4\times3\times2\times1=7206!=6×5×4×3×2×1=720.
Answer: 720720720.
Example 2: Permutation — arranging a subset in order
In how many ways can 333 of 777 different books be arranged on a shelf (order matters)?
Solution
Three ordered slots: 7 choices for the first, then 6, then 5 — order matters.
Identify: order matters (a different arrangement of the same 333 books is a different outcome), so this is a permutation. Use nPr=n!(n−r)!_{n}P_{r}=\dfrac{n!}{(n-r)!}n​Pr​=(n−r)!n!​ with n=7n=7n=7, r=3r=3r=3.
Compute: 7P3=7!4!=7×6×5×4!4!=7×6×5=210_{7}P_{3}=\dfrac{7!}{4!}=\dfrac{7\times6\times5\times4!}{4!}=7\times6\times5=2107​P3​=4!7!​=4!7×6×5×4!​=7×6×5=210.
Answer: 210210210 ways.
Example 3: Combination — the same books, but order doesn't matter
In how many ways can 333 of the same 777 books be chosen (not arranged — order doesn't matter)?
Solution
The 3 circled books form one set — no matter what order they're named, it's the same selection.
Identify: order no longer matters (choosing books X, Y, Z is the same outcome regardless of the order named), so this is a combination. Use nCr=n!r!(n−r)!_{n}C_{r}=\dfrac{n!}{r!(n-r)!}n​Cr​=r!(n−r)!n!​ with n=7n=7n=7, r=3r=3r=3.
Compute: 7C3=7!3! 4!=7×6×53×2×1=2106=35_{7}C_{3}=\dfrac{7!}{3!\,4!}=\dfrac{7\times6\times5}{3\times2\times1}=\dfrac{210}{6}=357​C3​=3!4!7!​=3×2×17×6×5​=6210​=35.
Notice this equals 7P33!=2106=35\dfrac{_{7}P_{3}}{3!}=\dfrac{210}{6}=353!7​P3​​=6210​=35 — combinations always undercount permutations by the r!r!r! orderings that get treated as "the same" selection.
Answer: 353535 ways.
Example 4: P or C? — Officers with distinct roles
A club of 101010 people elects a president, vice-president, and secretary. How many ways can these three distinct roles be filled?
Solution
The roles are different, so swapping who gets which role creates a genuinely different outcome — this is a permutation.
10P3=10!7!=10×9×8=720_{10}P_{3}=\dfrac{10!}{7!}=10\times9\times8=72010​P3​=7!10!​=10×9×8=720.
Answer: 720720720 ways.
Example 5: P or C? — An unranked committee
The same club of 101010 people chooses 444 people (with no distinct roles) for a committee. How many ways?
Solution
No roles to distinguish the four — this is a combination.
10C4=10!4! 6!=10×9×8×74×3×2×1=504024=210_{10}C_{4}=\dfrac{10!}{4!\,6!}=\dfrac{10\times9\times8\times7}{4\times3\times2\times1}=\dfrac{5040}{24}=21010​C4​=4!6!10!​=4×3×2×110×9×8×7​=245040​=210.
Answer: 210210210 ways.
Example 6: Why $0!=1$
Explain why 0!0!0! is defined to equal 111, not 000.
Solution
The factorial pattern is n!=n×(n−1)!n!=n\times(n-1)!n!=n×(n−1)!. Working this backward from n=1n=1n=1: 1!=1×0!1!=1\times0!1!=1×0!. Since 1!=11!=11!=1, we need 0!=10!=10!=1 to keep the pattern consistent.
It also matches counting logic: there is exactly 111 way to arrange zero objects (do nothing) — an empty arrangement is still one valid outcome, not zero outcomes.
Answer: 0!=10!=10!=1, by the recursive pattern and by counting logic (one way to arrange nothing).
Example 7: Reversing the relationship
If nC3=20_{n}C_{3}=20n​C3​=20, find nP3_{n}P_{3}n​P3​.
Solution
Use nPr=nCr×r!_{n}P_{r}={_{n}C_{r}}\times r!n​Pr​=n​Cr​×r!:
nP3=20×3!=20×6=120_{n}P_{3}=20\times3!=20\times6=120n​P3​=20×3!=20×6=120.
Answer: 120120120.
Example 8: Permutation with a fixed position (restriction)
555 runners finish a race; medals go to the top 333 finishers in order (1st, 2nd, 3rd). If a particular runner, Maria, is guaranteed to finish 1st, in how many ways can the remaining medal positions (2nd and 3rd) be filled?
Solution
Maria's spot is fixed, so only the other 444 runners compete for the 222 remaining ordered positions:
4P2=4×3=12_{4}P_{2}=4\times3=124​P2​=4×3=12.
Answer: 121212 ways.
Example 9: Fundamental Counting Principle + permutations — license plates
A license plate has 333 different letters (no repeats) followed by 333 different digits (no repeats). How many plates are possible?
Solution
×
Letter slots (top) shrink 26→25→24; digit slots (bottom) shrink 10→9→8. Multiply the two stages together.
Letters: choose and arrange 333 of 262626 letters, order matters (position matters on a plate): 26P3=26×25×24=15,600_{26}P_{3}=26\times25\times24=15{,}60026​P3​=26×25×24=15,600.
Digits: choose and arrange 333 of 101010 digits: 10P3=10×9×8=720_{10}P_{3}=10\times9\times8=72010​P3​=10×9×8=720.
Combine with the Fundamental Counting Principle (multiply independent stages): 15,600×720=11,232,00015{,}600\times720=11{,}232{,}00015,600×720=11,232,000.
Answer: 11,232,00011{,}232{,}00011,232,000 possible plates.
Example 10: Combination with a required member
A committee of 555 is chosen from 121212 people, and Alex must be on it. How many committees are possible?
Solution
Since Alex's spot is guaranteed, only 444 more people need to be chosen — from the remaining 111111 people, order doesn't matter:
11C4=11!4! 7!=11×10×9×84×3×2×1=792024=330_{11}C_{4}=\dfrac{11!}{4!\,7!}=\dfrac{11\times10\times9\times8}{4\times3\times2\times1}=\dfrac{7920}{24}=33011​C4​=4!7!11!​=4×3×2×111×10×9×8​=247920​=330.
Answer: 330330330 committees.
Example 11: Capstone — combinations and probability together
A lottery requires picking the correct 666 numbers from 494949 (order doesn't matter). Given that 49C6=13,983,816_{49}C_{6}=13{,}983{,}81649​C6​=13,983,816, find the probability of winning with one ticket.
Solution
There is exactly 111 winning combination out of all 49C6_{49}C_{6}49​C6​ equally likely combinations:
P(win)=149C6=113,983,816P(\text{win})=\dfrac{1}{_{49}C_{6}}=\dfrac{1}{13{,}983{,}816}P(win)=49​C6​1​=13,983,8161​.
Answer: 113,983,816\dfrac{1}{13{,}983{,}816}13,983,8161​ — an illustration of how quickly combinations grow, and why lottery odds are so small.
