7.5 Coordinate Proofs for Quadrilaterals
On the coordinate plane, three algebraic tools let you prove exactly what kind of quadrilateral you have — no protractor needed. Slope (m=y2−y1x2−x1m=\dfrac{y_2-y_1}{x_2-x_1}m=x2​−x1​y2​−y1​​) tests parallel sides (equal slopes) and perpendicular sides (slopes multiply to −1-1−1). Distance (d=(x2−x1)2+(y2−y1)2d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}d=(x2​−x1​)2+(y2​−y1​)2​) tests congruent sides or diagonals. Midpoint tests whether diagonals bisect each other. Chain these together to climb the hierarchy: both pairs of opposite sides parallel ⇒\Rightarrow⇒ parallelogram; add perpendicular adjacent sides (or congruent diagonals) ⇒\Rightarrow⇒ rectangle; add congruent sides (or perpendicular diagonals) ⇒\Rightarrow⇒ rhombus; both ⇒\Rightarrow⇒ square. Only one pair of parallel sides ⇒\Rightarrow⇒ trapezoid. Two distinct pairs of consecutive congruent sides (with perpendicular diagonals but no parallel sides) ⇒\Rightarrow⇒ kite. This worksheet uses full coordinates and asks you to justify the most specific classification possible.

Examples

Example 1: Prove a parallelogram using slope
Vertices A(0,0)A(0,0)A(0,0), B(4,1)B(4,1)B(4,1), C(5,4)C(5,4)C(5,4), D(1,3)D(1,3)D(1,3). Show that ABCDABCDABCD is a parallelogram.
Solution
Opposite sides have equal slope, so AB‾∥DC‾\overline{AB}\parallel\overline{DC}AB∥DC and AD‾∥BC‾\overline{AD}\parallel\overline{BC}AD∥BC.
Slope of AB‾\overline{AB}AB: 1−04−0=14\dfrac{1-0}{4-0}=\dfrac{1}{4}4−01−0​=41​. Slope of DC‾\overline{DC}DC: 4−35−1=14\dfrac{4-3}{5-1}=\dfrac{1}{4}5−14−3​=41​. Equal ⇒AB‾∥DC‾\Rightarrow \overline{AB}\parallel\overline{DC}⇒AB∥DC.
Slope of AD‾\overline{AD}AD: 3−01−0=3\dfrac{3-0}{1-0}=31−03−0​=3. Slope of BC‾\overline{BC}BC: 4−15−4=3\dfrac{4-1}{5-4}=35−44−1​=3. Equal ⇒AD‾∥BC‾\Rightarrow \overline{AD}\parallel\overline{BC}⇒AD∥BC.
Both pairs of opposite sides are parallel, so ABCDABCDABCD is a parallelogram.
Example 2: Upgrade to a rectangle
In parallelogram ABCDABCDABCD, adjacent sides have slopes 222 and −12-\dfrac{1}{2}−21​. Show that ABCDABCDABCD must be a rectangle.
Solution
Two lines are perpendicular exactly when their slopes multiply to −1-1−1:
2×(−12)=−12\times\left(-\dfrac{1}{2}\right)=-12×(−21​)=−1.
So the adjacent sides meet at a right angle. Since ABCDABCDABCD is already a parallelogram, one right angle forces all four angles to be right angles (opposite angles congruent, consecutive angles supplementary).
Answer: ABCDABCDABCD is a rectangle.
Example 3: Prove a rhombus using distance
Vertices A(0,0)A(0,0)A(0,0), B(3,4)B(3,4)B(3,4), C(8,4)C(8,4)C(8,4), D(5,0)D(5,0)D(5,0). Show that ABCDABCDABCD is a rhombus.
Solution
All four sides have length 555.
AB=32+42=25=5AB=\sqrt{3^2+4^2}=\sqrt{25}=5AB=32+42​=25​=5.
BC=(8−3)2+(4−4)2=25=5BC=\sqrt{(8-3)^2+(4-4)^2}=\sqrt{25}=5BC=(8−3)2+(4−4)2​=25​=5.
CD=(5−8)2+(0−4)2=9+16=5CD=\sqrt{(5-8)^2+(0-4)^2}=\sqrt{9+16}=5CD=(5−8)2+(0−4)2​=9+16​=5.
DA=(0−5)2+(0−0)2=25=5DA=\sqrt{(0-5)^2+(0-0)^2}=\sqrt{25}=5DA=(0−5)2+(0−0)2​=25​=5.
All four sides equal 555, so ABCDABCDABCD is a rhombus. (It is also a parallelogram, since AB‾\overline{AB}AB and DC‾\overline{DC}DC are both the vector (3,4)(3,4)(3,4).)
Example 4: Verify a square using slope and distance together
Vertices A(0,0)A(0,0)A(0,0), B(4,0)B(4,0)B(4,0), C(4,4)C(4,4)C(4,4), D(0,4)D(0,4)D(0,4). Verify that ABCDABCDABCD is a square.
Solution
Sides equal? AB=4AB=4AB=4, BC=4BC=4BC=4, CD=4CD=4CD=4, DA=4DA=4DA=4 — all congruent.
Right angles? Slope of AB‾\overline{AB}AB is 000 (horizontal); slope of BC‾\overline{BC}BC is undefined (vertical). A horizontal side and a vertical side are always perpendicular, so ∠B=90∘\angle B=90^\circ∠B=90∘. The same reasoning applies at every vertex.
Four congruent sides and four right angles ⇒\Rightarrow⇒ square.
Example 5: Prove a trapezoid — only one pair parallel
Vertices A(0,0)A(0,0)A(0,0), B(6,0)B(6,0)B(6,0), C(4,3)C(4,3)C(4,3), D(1,3)D(1,3)D(1,3). Classify ABCDABCDABCD.
Solution
Slope of AB‾\overline{AB}AB: 0−06−0=0\dfrac{0-0}{6-0}=06−00−0​=0. Slope of DC‾\overline{DC}DC: 3−34−1=0\dfrac{3-3}{4-1}=04−13−3​=0. Equal ⇒AB‾∥DC‾\Rightarrow \overline{AB}\parallel\overline{DC}⇒AB∥DC.
Slope of AD‾\overline{AD}AD: 3−01−0=3\dfrac{3-0}{1-0}=31−03−0​=3. Slope of BC‾\overline{BC}BC: 3−04−6=−32\dfrac{3-0}{4-6}=-\dfrac{3}{2}4−63−0​=−23​. Not equal ⇒\Rightarrow⇒ AD‾\overline{AD}AD and BC‾\overline{BC}BC are not parallel.
Exactly one pair of opposite sides is parallel, so ABCDABCDABCD is a trapezoid (with bases AB‾\overline{AB}AB and DC‾\overline{DC}DC).
Example 6: Square from diagonals alone
A quadrilateral has diagonals from (0,0)(0,0)(0,0) to (6,6)(6,6)(6,6) and from (0,6)(0,6)(0,6) to (6,0)(6,0)(6,0). Classify the quadrilateral.
Solution
Diagonal 111 length: 62+62=62\sqrt{6^2+6^2}=6\sqrt{2}62+62​=62​. Diagonal 222 length: 62+62=62\sqrt{6^2+6^2}=6\sqrt{2}62+62​=62​ — congruent diagonals.
Slope of diagonal 111: 6−06−0=1\dfrac{6-0}{6-0}=16−06−0​=1. Slope of diagonal 222: 0−66−0=−1\dfrac{0-6}{6-0}=-16−00−6​=−1. Product =1×(−1)=−1=1\times(-1)=-1=1×(−1)=−1 — perpendicular diagonals.
Midpoint of diagonal 111: (3,3)(3,3)(3,3). Midpoint of diagonal 222: (3,3)(3,3)(3,3) — same midpoint, so the diagonals bisect each other (parallelogram).
Congruent, perpendicular diagonals that bisect each other ⇒\Rightarrow⇒ the quadrilateral is a square.
Example 7: Midpoint test proves a parallelogram
ABCDABCDABCD has diagonals AC‾\overline{AC}AC with A(1,2)A(1,2)A(1,2), C(7,8)C(7,8)C(7,8), and BD‾\overline{BD}BD with B(2,7)B(2,7)B(2,7), D(6,3)D(6,3)D(6,3). Show ABCDABCDABCD is a parallelogram.
Solution
Midpoint of AC‾\overline{AC}AC: (1+72,2+82)=(4,5)\left(\dfrac{1+7}{2},\dfrac{2+8}{2}\right)=(4,5)(21+7​,22+8​)=(4,5).
Midpoint of BD‾\overline{BD}BD: (2+62,7+32)=(4,5)\left(\dfrac{2+6}{2},\dfrac{7+3}{2}\right)=(4,5)(22+6​,27+3​)=(4,5).
Both diagonals share the same midpoint (4,5)(4,5)(4,5), so they bisect each other. A quadrilateral whose diagonals bisect each other is a parallelogram.
Example 8: Basic distance for adjacent sides
Points P(1,1)P(1,1)P(1,1), Q(4,1)Q(4,1)Q(4,1), R(4,5)R(4,5)R(4,5), S(1,5)S(1,5)S(1,5). Find PQPQPQ and PSPSPS.
Solution
PQ=(4−1)2+(1−1)2=9=3PQ=\sqrt{(4-1)^2+(1-1)^2}=\sqrt{9}=3PQ=(4−1)2+(1−1)2​=9​=3.
PS=(1−1)2+(5−1)2=16=4PS=\sqrt{(1-1)^2+(5-1)^2}=\sqrt{16}=4PS=(1−1)2+(5−1)2​=16​=4.
Answer: PQ=3PQ=3PQ=3; PS=4PS=4PS=4 (this is a 333-by-444 rectangle).
Example 9: Perpendicular slope check with fractions
Slopes m1=23m_1=\dfrac{2}{3}m1​=32​ and m2=−32m_2=-\dfrac{3}{2}m2​=−23​. Are the corresponding sides perpendicular?
Solution
Multiply the slopes: 23×(−32)=−66=−1\dfrac{2}{3}\times\left(-\dfrac{3}{2}\right)=-\dfrac{6}{6}=-132​×(−23​)=−66​=−1.
Since the product is −1-1−1, the sides are perpendicular.
Example 10: Capstone — classify as specifically as possible
Vertices A(0,0)A(0,0)A(0,0), B(5,2)B(5,2)B(5,2), C(7,7)C(7,7)C(7,7), D(2,5)D(2,5)D(2,5). Classify ABCDABCDABCD as specifically as possible.
Solution
Check for parallelogram (slopes): AB‾\overline{AB}AB: slope 25\dfrac{2}{5}52​; DC‾\overline{DC}DC: 7−57−2=25\dfrac{7-5}{7-2}=\dfrac{2}{5}7−27−5​=52​ — equal. AD‾\overline{AD}AD: slope 52\dfrac{5}{2}25​; BC‾\overline{BC}BC: 7−27−5=52\dfrac{7-2}{7-5}=\dfrac{5}{2}7−57−2​=25​ — equal. Both pairs parallel ⇒\Rightarrow⇒ parallelogram.
Check side lengths: AB=52+22=29AB=\sqrt{5^2+2^2}=\sqrt{29}AB=52+22​=29​; AD=22+52=29AD=\sqrt{2^2+5^2}=\sqrt{29}AD=22+52​=29​ — adjacent sides congruent, so all four sides are congruent (opposite sides already matched by the parallelogram property) ⇒\Rightarrow⇒ rhombus.
Check right angles: AB→=(5,2)\overrightarrow{AB}=(5,2)AB=(5,2), AD→=(2,5)\overrightarrow{AD}=(2,5)AD=(2,5). Dot product =5(2)+2(5)=20≠0=5(2)+2(5)=20\neq0=5(2)+2(5)=20=0, so the sides are not perpendicular — not a rectangle, so not a square.
Answer: ABCDABCDABCD is a rhombus that is not a square, with side length 29\sqrt{29}29​.
Example 11: Coordinate proof of a kite
Vertices A(0,3)A(0,3)A(0,3), B(2,0)B(2,0)B(2,0), C(0,−4)C(0,-4)C(0,−4), D(−2,0)D(-2,0)D(−2,0). Show that ABCDABCDABCD is a kite (and not a rhombus).
Solution
AB=22+32=13AB=\sqrt{2^2+3^2}=\sqrt{13}AB=22+32​=13​.
AD=22+32=13AD=\sqrt{2^2+3^2}=\sqrt{13}AD=22+32​=13​ — matches ABABAB.
BC=22+42=20BC=\sqrt{2^2+4^2}=\sqrt{20}BC=22+42​=20​.
CD=22+42=20CD=\sqrt{2^2+4^2}=\sqrt{20}CD=22+42​=20​ — matches BCBCBC, but 20≠13\sqrt{20}\neq\sqrt{13}20​=13​.
Two distinct pairs of consecutive congruent sides (AB=ADAB=ADAB=AD and CB=CDCB=CDCB=CD), with the pairs unequal to each other ⇒\Rightarrow⇒ ABCDABCDABCD is a kite, not a rhombus (a rhombus would need all four sides equal).
