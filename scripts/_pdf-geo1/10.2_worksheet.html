10.2 Volume
Volume measures the space enclosed by a solid, in cubic units. Prisms and cylinders use V=BhV=BhV=Bh (base area times height); pyramids and cones use exactly 13\dfrac1331​ of that, V=13BhV=\dfrac13BhV=31​Bh, because a pyramid/cone fills only a third of the prism/cylinder that encloses it; a sphere uses V=43πr3V=\dfrac43\pi r^{3}V=34​πr3. As with surface area, the height needed in the formula is the solid's true vertical height, which sometimes must be recovered from a slant height using the Pythagorean Theorem. This worksheet also covers composite solids, cone-vs-cylinder comparisons, reverse problems, and real-world capacity/unit-conversion problems.

Examples

Example 1: Rectangular prism
Find the volume of a rectangular prism with length 888, width 555, height 666.
Solution
Volume of a box = length × width × height.
Identify the dimensions: l=8l=8l=8, w=5w=5w=5, h=6h=6h=6.
Apply the box volume formula:
V=lwh=8(5)(6)=240V=lwh=8(5)(6)=240V=lwh=8(5)(6)=240.
Answer: 240240240 cubic units.
Example 2: Cube
Find the volume of a cube with edge length 777.
Solution
Identify the edge length: s=7s=7s=7.
A cube's volume is its edge length cubed:
V=s3=73=343V=s^{3}=7^{3}=343V=s3=73=343.
Answer: 343343343 cubic units.
Example 3: Cylinder
Find the volume of a cylinder with radius 444, height 999.
Solution
Base area πr2\pi r^2πr2 times height.
Identify the radius and height: r=4r=4r=4, h=9h=9h=9.
Apply the cylinder volume formula:
V=πr2h=π(16)(9)=144πV=\pi r^{2}h=\pi(16)(9)=144\piV=πr2h=π(16)(9)=144π.
Answer: 144π144\pi144π cubic units.
Example 4: Square pyramid — height given
A square pyramid has base edge 666 and height 101010. Find its volume.
Solution
Base area: B=62=36B=6^{2}=36B=62=36.
V=13Bh=13(36)(10)=3603=120V=\dfrac13Bh=\dfrac13(36)(10)=\dfrac{360}{3}=120V=31​Bh=31​(36)(10)=3360​=120.
Answer: 120120120 cubic units.
Example 5: Square pyramid — find the height first
A square pyramid has base edge 161616 and slant height 171717. Find its volume.
Solution
The formula needs the vertical height hhh, not the slant height ℓ=17\ell=17ℓ=17. Since ℓ\ellℓ is the hypotenuse of a right triangle with legs hhh and half the base edge:
h=ℓ2−(s2)2=172−82=289−64=225=15h=\sqrt{\ell^{2}-\left(\dfrac{s}{2}\right)^{2}}=\sqrt{17^{2}-8^{2}}=\sqrt{289-64}=\sqrt{225}=15h=ℓ2−(2s​)2​=172−82​=289−64​=225​=15.
Now find the base area: B=162=256B=16^{2}=256B=162=256.
V=13Bh=13(256)(15)=38403=1280V=\dfrac13Bh=\dfrac13(256)(15)=\dfrac{3840}{3}=1280V=31​Bh=31​(256)(15)=33840​=1280.
Answer: 128012801280 cubic units.
Example 6: Cone
Find the volume of a cone with radius 333, height 888.
Solution
A cone fills exactly 13\tfrac1331​ of the cylinder with the same base and height.
Identify the radius and height: r=3r=3r=3, h=8h=8h=8.
Apply the cone volume formula (one-third of the matching cylinder):
V=13πr2h=13π(9)(8)=72π3=24πV=\dfrac13\pi r^{2}h=\dfrac13\pi(9)(8)=\dfrac{72\pi}{3}=24\piV=31​πr2h=31​π(9)(8)=372π​=24π.
Answer: 24π24\pi24π cubic units.
Example 7: Sphere
Find the volume of a sphere with radius 666.
Solution
V=43πr3V=\tfrac43\pi r^3V=34​πr3 uses the radius cubed.
Identify the radius: r=6r=6r=6.
Apply the sphere volume formula:
V=43πr3=43π(216)=864π3=288πV=\dfrac43\pi r^{3}=\dfrac43\pi(216)=\dfrac{864\pi}{3}=288\piV=34​πr3=34​π(216)=3864π​=288π.
Answer: 288π288\pi288π cubic units.
Example 8: Composite solid — silo volume
A grain silo is a cylinder of radius 666 and height 101010 topped by a hemisphere of the same radius. Find its total volume.
Solution
+
Total volume = cylinder volume + hemisphere volume (half a sphere).
Cylinder: Vcyl=πr2h=π(36)(10)=360πV_{\text{cyl}}=\pi r^{2}h=\pi(36)(10)=360\piVcyl​=πr2h=π(36)(10)=360π.
Hemisphere (half a sphere of the same radius): Vhemi=12(43πr3)=23π(216)=144πV_{\text{hemi}}=\dfrac12\left(\dfrac43\pi r^{3}\right)=\dfrac23\pi(216)=144\piVhemi​=21​(34​πr3)=32​π(216)=144π.
Total: V=360π+144π=504πV=360\pi+144\pi=504\piV=360π+144π=504π.
Answer: 504π504\pi504π cubic units.
Example 9: Cone vs. cylinder — same base and height
A cone and a cylinder both have radius 555 and height 121212. Find each volume and compare.
Solution
Cylinder: V=πr2h=π(25)(12)=300πV=\pi r^{2}h=\pi(25)(12)=300\piV=πr2h=π(25)(12)=300π.
Cone: V=13πr2h=13(300π)=100πV=\dfrac13\pi r^{2}h=\dfrac13(300\pi)=100\piV=31​πr2h=31​(300π)=100π.
Comparison: the cone's volume is exactly 13\dfrac1331​ of the cylinder's — this is true for any cone/cylinder pair sharing a base and height, not just this one.
Answers: cylinder =300π=300\pi=300π; cone =100π=100\pi=100π.
Example 10: Reverse problem — solve for a missing dimension
A cylinder has radius 555 and volume 250π250\pi250π. Find its height.
Solution
V=πr2h  ⇒  250π=π(25)hV=\pi r^{2}h \;\Rightarrow\; 250\pi=\pi(25)hV=πr2h⇒250π=π(25)h
Divide both sides by 25π25\pi25π: h=250π25π=10h=\dfrac{250\pi}{25\pi}=10h=25π250π​=10.
Check: π(25)(10)=250π\pi(25)(10)=250\piπ(25)(10)=250π. ✓
Answer: h=10h=10h=10.
Example 11: Word problem — capacity in liters
A cylindrical water tank has diameter 222 m and height 333 m. Find its volume in cubic meters, then convert to liters (1 m3=10001\text{ m}^3=10001 m3=1000 L).
Solution
Radius: r=22=1r=\dfrac{2}{2}=1r=22​=1 m.
V=πr2h=π(1)2(3)=3πV=\pi r^{2}h=\pi(1)^{2}(3)=3\piV=πr2h=π(1)2(3)=3π m3^33 (exact form).
Using π≈3.14159\pi\approx3.14159π≈3.14159: V≈9.42V\approx9.42V≈9.42 m3^33.
Convert: 9.42 m3×1000Lm3≈94209.42\text{ m}^3\times1000\dfrac{\text{L}}{\text{m}^3}\approx94209.42 m3×1000m3L​≈9420 L.
Answer: 3π3\pi3π m3≈9420^3\approx94203≈9420 L.
