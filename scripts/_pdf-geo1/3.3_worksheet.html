3.3 Rotations
A rotation turns every point of a figure through the same angle about a fixed center, which is why every image point stays exactly as far from the center as its preimage did. Beyond the three memorized rules for rotating about the origin (90∘90^\circ90∘, 180∘180^\circ180∘, 270∘270^\circ270∘), this section extends rotation to a center that is not the origin (translate the center to the origin, rotate, translate back), works backward to identify an unknown rotation angle from a point and its image, and previews how repeated rotations connect to rotational symmetry in Section 3.5.

Examples

Example 1: $90^\circ$ counterclockwise about the origin
Rotate (2,1)(2, 1)(2,1) 90∘90^\circ90∘ CCW about the origin, and explain where the rule (x,y)→(−y,x)(x,y)\to(-y,x)(x,y)→(−y,x) comes from.
Solution
A quarter-turn CCW about the origin swaps coordinates and negates the new x.
Rule: a 90∘90^\circ90∘ CCW rotation about the origin sends (x,y)→(−y,x)(x,y)\to(-y,x)(x,y)→(−y,x) — swap the coordinates, then negate the new xxx.
Apply it: (2,1)→(−1,2)(2,1)\to(-1,2)(2,1)→(−1,2).
Check: both points are the same distance from the origin, 22+12=5=(−1)2+22\sqrt{2^2+1^2}=\sqrt5=\sqrt{(-1)^2+2^2}22+12​=5​=(−1)2+22​. ✓
Answer: (−1,2)(-1, 2)(−1,2).
Example 2: $180^\circ$ about the origin
Rotate (3,−4)(3, -4)(3,−4) 180∘180^\circ180∘ about the origin.
Solution
180° is a straight-through turn — negate both coordinates.
A 180∘180^\circ180∘ rotation is a half-turn, equivalent to two 90∘90^\circ90∘ turns in a row, which negates both coordinates: (x,y)→(−x,−y)(x,y)\to(-x,-y)(x,y)→(−x,−y).
(3,−4)→(−3,4)(3,-4)\to(-3,4)(3,−4)→(−3,4).
Answer: (−3,4)(-3, 4)(−3,4).
Example 3: $270^\circ$ counterclockwise about the origin
Rotate (2,5)(2, 5)(2,5) 270∘270^\circ270∘ CCW about the origin.
Solution
Rule: 270∘270^\circ270∘ CCW (the same as 90∘90^\circ90∘ clockwise) sends (x,y)→(y,−x)(x,y)\to(y,-x)(x,y)→(y,−x).
(2,5)→(5,−2)(2,5)\to(5,-2)(2,5)→(5,−2).
Answer: (5,−2)(5, -2)(5,−2).
Example 4: Rotate a whole triangle
△DEF\triangle DEF△DEF has D(1,2)D(1,2)D(1,2), E(4,2)E(4,2)E(4,2), F(1,5)F(1,5)F(1,5). Rotate 180∘180^\circ180∘ about the origin. Find all three image vertices.
Solution
Every vertex negates both coordinates under a 180° turn.
Apply (x,y)→(−x,−y)(x,y)\to(-x,-y)(x,y)→(−x,−y) to each vertex: D′=(−1,−2)D'=(-1,-2)D′=(−1,−2); E′=(−4,−2)E'=(-4,-2)E′=(−4,−2); F′=(−1,−5)F'=(-1,-5)F′=(−1,−5).
Answer: D′(−1,−2)D'(-1,-2)D′(−1,−2), E′(−4,−2)E'(-4,-2)E′(−4,−2), F′(−1,−5)F'(-1,-5)F′(−1,−5).
Example 5: Why rotations preserve distance
Show algebraically that a 90∘90^\circ90∘ rotation about the origin preserves the distance between two points.
Solution
Let P1=(x1,y1)P_1=(x_1,y_1)P1​=(x1​,y1​), P2=(x2,y2)P_2=(x_2,y_2)P2​=(x2​,y2​), rotated to P1′=(−y1,x1)P_1'=(-y_1,x_1)P1′​=(−y1​,x1​), P2′=(−y2,x2)P_2'=(-y_2,x_2)P2′​=(−y2​,x2​).
The new coordinate differences are −y2−(−y1)=−(y2−y1)-y_2-(-y_1) = -(y_2-y_1)−y2​−(−y1​)=−(y2​−y1​) and x2−x1x_2-x_1x2​−x1​ — the same two differences as before, just swapped and one sign-flipped.
Since the distance formula squares both differences, the sign flip and the swap don't change the result: (−(y2−y1))2+(x2−x1)2=(x2−x1)2+(y2−y1)2(-(y_2-y_1))^2+(x_2-x_1)^2 = (x_2-x_1)^2+(y_2-y_1)^2(−(y2​−y1​))2+(x2​−x1​)2=(x2​−x1​)2+(y2​−y1​)2.
Answer: The distance is identical before and after, so rotations preserve distance.
Example 6: Orientation is preserved
Does a rotation reverse a figure's orientation, the way a reflection does? Explain.
Solution
A rotation only turns a figure rigidly around a fixed point — it never flips the figure over, so the clockwise/counterclockwise order of its vertices stays the same.
Answer: No — rotations preserve orientation, along with translations; only reflections (and glide reflections) reverse it.
Example 7: Rotating about a point other than the origin
Rotate (5,3)(5, 3)(5,3) 90∘90^\circ90∘ CCW about the center (2,3)(2, 3)(2,3) (not the origin).
Solution
Shift the center to the origin, rotate, then shift back.
Step 1 — shift so the center is at the origin: subtract (2,3)(2,3)(2,3) from the point: (5−2, 3−3)=(3,0)(5-2,\ 3-3)=(3,0)(5−2, 3−3)=(3,0).
Step 2 — apply the 90∘90^\circ90∘ CCW rule (x,y)→(−y,x)(x,y)\to(-y,x)(x,y)→(−y,x): (3,0)→(0,3)(3,0)\to(0,3)(3,0)→(0,3).
Step 3 — shift back by adding (2,3)(2,3)(2,3): (0+2, 3+3)=(2,6)(0+2,\ 3+3)=(2,6)(0+2, 3+3)=(2,6).
Check: distance from center to (5,3)(5,3)(5,3) is 333; distance from center to (2,6)(2,6)(2,6) is 02+32=3\sqrt{0^2+3^2}=302+32​=3. ✓
Answer: (2,6)(2, 6)(2,6).
Example 8: Identify the rotation from a point and its image
A point (2,3)(2,3)(2,3) maps to (−3,2)(-3,2)(−3,2) under a rotation about the origin. Which rotation is it?
Solution
Compare to the three rules: 90∘90^\circ90∘ CCW gives (x,y)→(−y,x)(x,y)\to(-y,x)(x,y)→(−y,x), so (2,3)→(−3,2)(2,3)\to(-3,2)(2,3)→(−3,2) — an exact match.
Answer: 90∘90^\circ90∘ counterclockwise (equivalently, 270∘270^\circ270∘ clockwise).
Example 9: Composing two $90^\circ$ rotations
Rotate (x,y)(x,y)(x,y) by 90∘90^\circ90∘ CCW, then rotate that image by another 90∘90^\circ90∘ CCW. Show the result matches the single 180∘180^\circ180∘ rule.
Solution
First rotation: (x,y)→(−y,x)(x,y)\to(-y,x)(x,y)→(−y,x).
Second rotation applied to (−y,x)(-y,x)(−y,x): using the rule (a,b)→(−b,a)(a,b)\to(-b,a)(a,b)→(−b,a) with a=−y, b=xa=-y,\ b=xa=−y, b=x, we get (−x,−y)(-x,-y)(−x,−y).
Answer: (−x,−y)(-x,-y)(−x,−y) — exactly the 180∘180^\circ180∘ rule, confirming that two 90∘90^\circ90∘ turns combine into one 180∘180^\circ180∘ turn (a preview of composing transformations in Section 3.4).
Example 10: From repeated rotation to rotational symmetry
A figure looks unchanged after being rotated 72∘72^\circ72∘ about its center. How many such rotations are needed to complete a full 360∘360^\circ360∘ turn, and what does this preview about Section 3.5?
Solution
Divide the full turn by the repeating angle: 360∘÷72∘=5360^\circ \div 72^\circ = 5360∘÷72∘=5.
Preview: a figure that repeats every 72∘72^\circ72∘ has rotational symmetry of order 555 (like a regular pentagon) — Section 3.5 studies exactly this kind of repeat-angle counting.
Answer: 555 rotations of 72∘72^\circ72∘ complete the full turn.
