1.6 Introduction to Proofs
A proof is a chain of true statements, each one justified by a definition, postulate, theorem, or algebraic property — no step is allowed to appear "because it looks true." This section reviews the algebraic properties (reflexive, symmetric, transitive, substitution, addition/subtraction) that fill in most proof reasons, then builds up to full two-column proofs that combine several of them in one argument, such as showing two overlapping segments are equal or formally proving the Vertical Angles Theorem instead of just quoting it.

Examples

Example 1: Reflexive Property
Justify the statement AB=ABAB = ABAB=AB.
Solution
A reflexive statement compares a quantity to itself, and any quantity is always equal to itself, no matter what it represents.
This property is used constantly in proofs to introduce a side or angle that two figures share.
Answer: Reflexive Property of Equality.
Example 2: Symmetric Property
If AB=CDAB = CDAB=CD, then CD=ABCD = ABCD=AB. What justifies this step?
Solution
Equality does not have a direction — if one quantity equals a second, the second equals the first.
This lets you "flip" a given equation whenever it is more convenient to work with the reversed order.
Answer: Symmetric Property of Equality.
Example 3: Transitive Property
Given AB=CDAB = CDAB=CD and CD=EFCD = EFCD=EF, conclude AB=EFAB = EFAB=EF. Justify the step, then apply it: if AB=5AB = 5AB=5, find EFEFEF.
Solution
Two quantities each equal to the same third quantity must equal each other — that's the Transitive Property of Equality.
Since AB=CDAB = CDAB=CD and CD=EFCD = EFCD=EF, we get AB=EFAB = EFAB=EF directly, without needing to know CDCDCD's value.
Answer: Transitive Property of Equality; since AB=5AB = 5AB=5, also EF=5EF = 5EF=5.
Example 4: Substitution Property
If x=5x = 5x=5 and y=x+2y = x + 2y=x+2, conclude y=7y = 7y=7. What justifies replacing xxx with 555?
Solution
The Substitution Property allows any quantity to be replaced by another quantity already known equal to it.
Replace xxx with 555 in y=x+2y = x+2y=x+2: y=5+2=7y = 5+2 = 7y=5+2=7.
Answer: Substitution Property of Equality.
Example 5: Addition Property of Equality
If AB=CDAB = CDAB=CD, justify adding EFEFEF to both sides to get AB+EF=CD+EFAB + EF = CD + EFAB+EF=CD+EF.
Solution
The Addition Property says that adding the same quantity to both sides of a true equation keeps it true.
This step is the algebraic engine behind Segment Addition proofs: it lets you turn a given equality of two pieces into an equality of two larger sums.
Answer: Addition Property of Equality.
Example 6: Definition of midpoint
MMM is the midpoint of AB‾\overline{AB}AB. What can you conclude, and which definition justifies it?
Solution
M splits AB into two congruent halves.
By definition, a midpoint divides a segment into two congruent pieces.
So AM‾≅MB‾\overline{AM} \cong \overline{MB}AM≅MB, which by the definition of congruent segments also means AM=MBAM = MBAM=MB.
Answer: AM=MBAM = MBAM=MB (Definition of Midpoint).
Example 7: Definition of congruent segments
If AB‾≅CD‾\overline{AB} \cong \overline{CD}AB≅CD, what can you conclude about their lengths — and is the reverse direction also true?
Solution
By definition, congruent segments have equal length: AB‾≅CD‾⇒AB=CD\overline{AB}\cong\overline{CD} \Rightarrow AB = CDAB≅CD⇒AB=CD.
The definition works both ways — it is really a biconditional (recall Section 1.5): equal length also implies congruence, AB=CD⇒AB‾≅CD‾AB = CD \Rightarrow \overline{AB}\cong\overline{CD}AB=CD⇒AB≅CD.
Answer: AB=CDAB = CDAB=CD; yes, the reverse direction holds too, since "congruent" and "equal length" mean the same thing for segments.
Example 8: Vertical Angles Theorem
Two angles are vertical angles. What can you conclude, and is this a postulate or a theorem?
Solution
∠1 and ∠3 are vertical; so are ∠2 and ∠4.
By the Vertical Angles Theorem, vertical angles are always congruent.
It is a theorem, not a postulate — unlike a postulate, it must be (and has been) proved from more basic facts, specifically the Linear Pair Postulate and the Congruent Supplements Theorem.
Answer: The angles are congruent; this is a theorem.
Example 9: A short two-column proof
Given: AAA, BBB, CCC, DDD are collinear in that order, and AB=CDAB = CDAB=CD. Prove: AC=BDAC = BDAC=BD.
Solution
Points in order A, B, C, D on one line.
1. AB=CDAB = CDAB=CD — Given
2. BC=BCBC = BCBC=BC — Reflexive Property of Equality
3. AB+BC=CD+BCAB + BC = CD + BCAB+BC=CD+BC — Addition Property of Equality (adding the same quantity, step 2, to both sides of step 1)
4. AB+BC=ACAB + BC = ACAB+BC=AC and BC+CD=BDBC + CD = BDBC+CD=BD — Segment Addition Postulate (since BBB is between A,CA,CA,C and CCC is between B,DB,DB,D)
5. AC=BDAC = BDAC=BD — Substitution (replace AB+BCAB+BCAB+BC and CD+BCCD+BCCD+BC in step 3 using step 4)
∎ Proved: AC=BDAC = BDAC=BD.
Example 10: Proving the Vertical Angles Theorem
Given: ∠1\angle 1∠1 and ∠2\angle 2∠2 form a linear pair, and ∠2\angle 2∠2 and ∠3\angle 3∠3 form a linear pair (so ∠1\angle 1∠1 and ∠3\angle 3∠3 are vertical angles). Prove: m∠1=m∠3m\angle 1 = m\angle 3m∠1=m∠3.
Solution
∠1, ∠2, ∠3 around the intersection; ∠1 and ∠3 are vertical.
1. ∠1,∠2\angle 1, \angle 2∠1,∠2 are a linear pair; ∠2,∠3\angle 2, \angle 3∠2,∠3 are a linear pair — Given
2. m∠1+m∠2=180∘m\angle 1 + m\angle 2 = 180^\circm∠1+m∠2=180∘ and m∠2+m∠3=180∘m\angle 2 + m\angle 3 = 180^\circm∠2+m∠3=180∘ — Linear Pair Postulate
3. m∠1+m∠2=m∠2+m∠3m\angle 1 + m\angle 2 = m\angle 2 + m\angle 3m∠1+m∠2=m∠2+m∠3 — Substitution (both sums equal 180∘180^\circ180∘)
4. m∠1=m∠3m\angle 1 = m\angle 3m∠1=m∠3 — Subtraction Property of Equality (subtract m∠2m\angle 2m∠2 from both sides)
∎ Proved: vertical angles ∠1\angle 1∠1 and ∠3\angle 3∠3 are congruent.
